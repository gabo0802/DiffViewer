# DiffViewer (V1 scaffold)

Minimal Tauri + React (Vite) scaffold for the Diff Editor project.

Quick start (dev machine must have Node.js and Rust + Tauri prerequisites):

```bash
npm install
npm run dev
# In another terminal (if you have tauri installed):
# npm run tauri:dev
```
